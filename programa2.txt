// Programa de ejemplo 2: mayor de dos numeros
// Lee X y Y; si X-Y >= 0 (X es mayor o igual) muestra X, si no muestra Y.
// XMAYOR se usa en BRP XMAYOR antes de estar definida mas abajo: ejercita
// que el ensamblador resuelva etiquetas hacia adelante.
        INP
        STA X
        INP
        STA Y
        LDA X
        SUB Y
        BRP XMAYOR
        LDA Y
        OUT
        BRA FIN
XMAYOR  LDA X
        OUT
FIN     HLT
X       DAT 000
Y       DAT 000
